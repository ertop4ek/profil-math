# Профиль — тренажёр математики

Русскоязычный сайт для подготовки к профильному ЕГЭ по математике по формату 2026 года. Ученик может решать задачи без регистрации и входа.

## Как ученик работает с задачей

1. Выбирает номер задания ЕГЭ или тему и открывает задачу из подборки.
2. Вводит краткий ответ или записывает развёрнутое решение и получает обратную связь.
3. При необходимости открывает одну из пяти подсказок, полное решение или пошаговый ИИ-разбор.
4. Из карточки задания может перейти к памятке и урокам по той же теме.

## Требования к сайту

- Собрать большой банк проверенных заданий по всем номерам обеих частей экзамена.
- В первой части сопроводить каждую геометрическую задачу рисунком. Если условие задачи первой части опирается на график, показать этот график в карточке.
- Использовать крупный контрастный текст и понятную навигацию. Выбор задачи, чтение условия и ввод решения должны быть удобны на телефоне.
- Основная площадка — GitHub Pages. Основные функции работают в браузере из статической сборки. Проверку доступа из РФ фиксировать отдельно для мобильной и домашней сети.

## Порядок разработки

- В начале каждой новой сессии по проекту перечитывать `PROJECT.md`.
- Выполнять один шаг за раз. Перед изменениями изучать существующие страницы, маршруты, компоненты и данные. Переиспользовать то, что уже работает.
- Сохранять подходящий стек существующего сайта. Переиспользовать работающий интерфейс. Для GitHub Pages использовать статическую сборку с hash-маршрутами, относительными ресурсами и JSON по номерам.
- В конце каждого шага перечислять внесённые изменения, выполненные проверки и реальные ограничения.

## Видео и ИИ-разбор

- В карточке задания и разделе «Как решать» плеер выбирает MP4 по номеру и шаблону задания. GitHub Actions создаёт отдельный ролик для каждого из 94 типов по условию, формулам и шагам из банка. Ролики идут без озвучки. Локальная команда полной сборки — `npm run build:pages:videos` с установленным FFmpeg и шрифтом DejaVu Sans. В сборках без MP4 отображаются главы исходного разбора на RUTUBE.
- Кнопка ИИ-разбора в статической сборке готовит запрос с условием задачи и открывает ChatGPT в отдельной вкладке. Черновик включается по выбору ученика. Чат внутри тренажёра потребует отдельного серверного сервиса.

- Каждый мини-урок содержит встроенный пошаговый плеер на основе материалов этого урока. Плеер показывает формулы, шаги решения и рисунки учебных примеров. Доступны автопоказ, пауза и переход к нужному шагу. Это слайды без озвучки. Главы RUTUBE по 19 номерам доступны отдельно.

## Аккаунты

Серверная сборка поддерживает регистрацию по логину, паролю и почте, а также подтверждение входа одноразовым кодом из письма. D1 хранит аккаунты, сессии и отдельный прогресс. Тренировки, избранное и отметки по урокам синхронизируются при входе. Пробный ЕГЭ хранится отдельно для каждого аккаунта в текущем браузере. Гостевой прогресс сохраняется отдельно, его можно перенести через экспорт и импорт.

Для запуска нужен сайт с серверным API, применённая к D1 миграция `drizzle/0001_accounts.sql` и секреты `PROFILE_MAIL_KEY`, `PROFILE_MAIL_FROM` и `PROFILE_OTP_SECRET`. Отправитель должен быть подтверждён в Resend. GitHub Pages использует статическую сборку, в которой аккаунты отключены.
