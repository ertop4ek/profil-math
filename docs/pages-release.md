# Шаги 8–10

## Результаты реализации

Шаг 8 добавляет измеряемую точность первой части, подсчёт попыток, повторение ошибок, самостоятельное решение, решение с помощью и отдельные отметки самопроверки второй части. Миграция сохраняет старые попытки. В точности учитываются попытки с сохранённым результатом. Исправленная ошибка исчезает из списка повторения. Прогресс переносится JSON-файлом с проверкой версии и записей.

Шаг 9 добавляет 19 заданий с одним заданием на каждый номер, сохранение ответов, черновиков, отметок и времени. Таймер показывает оставшееся от 235 минут время. Завершение выполняет ученик с подтверждением. Первая часть проверяется после завершения, вторая проверяется по эталону. Состав и результат сохраняются при обновлении.

Шаг 10 подготовлен до публикации. Существующая разметка и модули переиспользуются в отдельной статической сборке. Команда npm run build:pages создаёт pages-dist. В ней нет серверного приложения. Маршруты вида #/practice/id работают в корне и подпапке. Данные разбиты по 19 номерам. CSS, рисунки и математический рендеринг входят в сборку. Ответы доступны в статических файлах, вариант служит для самопроверки.

Workflow .github/workflows/pages.yml запускается при push в main и вручную. В нём используются npm ci, проверки, сборка, upload-pages-artifact@v4 и deploy-pages@v4. Деплой получает только pages:write и id-token:write, сборка — contents:read.

## Публикация владельцем

Подключить GitHub к этой сессии и выбрать аккаунт. Создать публичный репозиторий, загрузить исходники, выбрать в Settings → Pages источник GitHub Actions. Запустить Publish GitHub Pages. Итоговый адрес брать из вывода deploy-pages.

После публикации проверить сайт с выключенным VPN в российской мобильной и домашней сети. Для каждой проверки сохранить дату, оператора, тип сети, URL и результаты открытия каталога, проверки ответа, пяти подсказок, рисунка, уроков, прогресса и варианта.

Если страница не открывается, записать текст ошибки, проверить разрешение DNS, подключение HTTPS и загрузку HTML. Если HTML открывается, проверить неудачные запросы ресурсов в инструментах браузера. Наличие проблемы с инфраструктурой пока не установлено, зеркало не развёртывалось.
